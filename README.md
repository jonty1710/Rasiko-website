# Rasiko Website

Mobile-first single-page frontend for Rasiko home-style catering.

## Run
Open `index.html` directly in a browser, or use any static server.

## Before launch
1. WhatsApp and calling number are configured for `9749661020`.
2. Replace `₹XXX` package prices.
3. Replace gallery/hero Unsplash images with Rasiko's own food/event photography.
4. Add real Instagram/Facebook URLs.
5. Add the final FSSAI registration number.
6. Update business hours/service area if needed.
7. Add a real domain and analytics/Search Console if desired.

## Structure
- `index.html` — semantic page + SEO metadata
- `styles.css` — responsive visual system
- `script.js` — mobile nav + WhatsApp enquiry form

The layout leaves room for a future `/shop` or Shop section without changing the current catering structure.
